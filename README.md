# Samuel Adeniran - Backend Developer Portfolio

A modern, high-performance portfolio website tailored for a **Backend & Systems Engineer**. Built with clean semantic HTML5, modern vanilla CSS (Obsidian dark aesthetic, responsive design, glowing telemetry accents), and vanilla JavaScript.

## 🚀 Live Preview & Running Locally

To view the portfolio locally:
1. Simply double-click `index.html` to open it in your browser.
2. Or run a local HTTP server:
   ```bash
   npx serve .
   ```
   Then open `http://localhost:3000` in your browser.

## 🛠️ How to Edit Content & Add Projects

All your portfolio information is stored in a single, easy-to-edit configuration file:
👉 **[`js/portfolio-data.js`](js/portfolio-data.js)**

You can update:
- **Personal Details & Bio**: Name, contact numbers, email, LinkedIn, GitHub, Instagram.
- **Production Experience**: Advantage Health Africa bullet points, metrics, and tech stack tags.
- **Projects**: Add new APIs, GitHub repositories, descriptions, and live URLs.
- **Skills**: Backend, databases, low-level languages (C, C++, Java), and applied AI tools.
- **Certifications**: AltSchool Africa, Postman API Student Expert, freeCodeCamp, HackerRank, etc.

## 🌐 Free Deployment Options

You can deploy this portfolio for free in under 2 minutes:

### 1. GitHub Pages (Recommended)
1. Push this folder to a GitHub repository (e.g. `samuel2770/portfolio` or `samuel2770.github.io`).
2. Go to **Settings > Pages**.
3. Under **Branch**, select `main` and root `/`, then click **Save**.
4. Your site will be live at `https://samuel2770.github.io/`!

### 2. Vercel
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` in this directory and follow the prompts.

### 3. Render
1. Connect your GitHub repository to Render as a **Static Site**.
2. Set publish directory to `./`.
